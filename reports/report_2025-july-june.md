## What is Curiosity Weekends?  
Curiosity Weekends is a community-driven tinkering initiative, primarily led by high school students, focusing on:  

- Learning through making and tinkering  
- Peer-to-peer learning  

---

## Genesis  
In mid-2024, a group of students began gathering on the second Saturday of each month, emphasizing:

- Learning through sharing  
- Puzzle-solving and treasure hunts  
- Hackathons  

By March 2025, the need for a shared workspace during summer vacation led to discussions with Linnk Academy. This collaboration resulted in the establishment of the **Curiosity Lab** on the first floor of **ASAP, Vidyanagar, Kasaragod**, generously provided by Linnk Academy.

---

## Philosophy  
> A baby learns to walk not by studying physics but through curious, playful attempts and learning from failures.

Similarly, learning, skill-building, product development, and even running a factory can be enjoyable when approached with curiosity and a willingness to embrace failures sustainably.

### ✅ **Drone Control via PC Payload Reverse Engineering**  
- **Contributor**: *Harsharaj Shetty B*  
- **Status**: Takeoff and fan control tested successfully  
- **Tech Stack**: Python, Wireshark, PCAPdroid, UDP socket programming  
- **What It Solves**: Replacing lost RC controller using PC-based system  
- **Approach**:  
  - Captured payloads via PCAPdroid on Android while using RCFPVPro drone app  
  - Identified UDP payloads corresponding to control actions (e.g., Takeoff)  
  - Wrote custom Python script to transmit those payloads to drone over Wi-Fi  
- **Next**:  
  - Implement full keyboard-based controls (WASD + Space)  
  - Add live feedback and telemetry  
  - Create a GUI interface and publish code as open source
